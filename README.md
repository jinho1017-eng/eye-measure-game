# 📏 눈대중 마스터

자 없이 눈으로만 길이·각도·넓이를 맞히는 웹 게임입니다. 정확할수록 높은 점수를 받습니다.

## 게임 방법
- 5라운드(또는 10라운드) 동안 문제를 풀고 라운드마다 0~100점을 받습니다.
- 숫자를 입력하거나 화면을 클릭해서 답합니다. `Enter`로 제출하고 다음으로 넘어갈 수 있습니다.
- **오늘의 도전**은 날짜를 기준으로 매일 같은 문제가 나옵니다. 친구와 점수를 비교해 보세요.
- 결과 화면에서 점수를 복사해 공유할 수 있습니다.

## 문제 유형 (9가지)
| 유형 | 방식 |
|---|---|
| 길이 | 기준선을 100으로 보고 선의 길이를 입력 |
| 각도 | 두 선 사이의 각도를 입력 |
| 넓이 | 정사각형을 100으로 보고 원의 넓이를 입력 |
| 점 개수 | 흩어진 점의 개수를 어림해서 입력 |
| 중점 | 두 점의 가운데를 클릭 |
| 같은 거리 | 기준선과 같은 거리 지점을 클릭 |
| 원의 중심 | 일부만 보이는 원호의 중심을 클릭 |
| 직각 | 주어진 선과 90°가 되는 방향을 클릭 |
| 삼등분점 | 두 점 사이 1/3 지점을 클릭 |

## 실행 방법
빌드 도구가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

로컬 서버로 실행하려면 다음 명령을 사용합니다.

```bash
npx serve .
```

## 기술
- HTML, CSS, JavaScript (Canvas, WebAudio), 외부 라이브러리 없음
- 최고 점수는 브라우저 `localStorage`에 저장되며 서버나 로그인은 사용하지 않습니다.

## 파일 구성
- `index.html` 화면 구조
- `style.css` 스타일
- `game.js` 게임 로직, 문제 유형 정의
- `PROMPT.md` 이 게임을 만드는 데 사용한 프롬프트
